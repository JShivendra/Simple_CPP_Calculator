# Simple_CPP_Calculator
A simple console-based calculator written in C++.
Simple C++ Calculator

A simple console-based calculator written in C++ as a Programming Fundamentals project.

Features

The calculator supports:

Addition +
Subtraction -
Multiplication *
Division /
Power ^
Repeated calculations
Concepts Used

This project demonstrates basic C++ programming concepts, including:

Console input and output using cin and cout
Functions and function prototypes
Function parameters
switch statements
while loops
Conditional logic
double data types
The <cmath> library and pow() function
How It Works

The user enters two numbers and selects an operation. The calculator performs the selected calculation and displays the result.

The user can then choose whether to perform another calculation.

Example
============================
    SIMPLE CALCULATOR
============================

Enter two numbers for calculations.
Notice : The first number shall be considered the dividend in case of division

10 2

Select an operation:
Multiplication  *
Division        /
Addition        +
Subtraction     -
Power           ^
Enter choice: /

Division of the two numbers is :5

Do you want to repeat ? Press Y/n
Requirements
A C++ compiler
Visual Studio or another C++ development environment
Running the Program

Open calculator.cpp in a C++ IDE such as Visual Studio and compile and run the program.

Project Purpose

This project was created to practice fundamental C++ programming concepts and build a simple working console application.
